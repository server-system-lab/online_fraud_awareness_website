# Online Fraud Awareness Platform (NovaShield AI)

Educational project focused on raising awareness about online fraud and cybersecurity risks.

This project combines a public website with a 3D animated video to explain common fraud scenarios and how to prevent them.

---

## Website

Access the platform here:  
https://novashieldai-maker.github.io/website/

The website presents:
- Common types of online fraud
- Prevention strategies
- Clear and accessible explanations for non-technical users

---

## Video

Watch the video here:  
https://www.youtube.com/watch?v=IrrkE4aCkbs

- Created using Blender
- Illustrates real-world fraud scenarios
- Designed to communicate cybersecurity risks in a simple and visual way

---

## Technologies

- HTML, CSS, JavaScript
- Vite
- Blender (for 3D animation)

---

## Purpose

The goal of this project is to:
- Increase awareness of online fraud
- Make cybersecurity concepts easier to understand
- Combine technical and visual approaches for effective communication

---

## Notes

This is an educational project developed to explore the intersection between technology, communication, and digital security.
